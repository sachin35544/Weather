# ☁️ Weather App

<p align="center">
  <img src="./assets/cloud.png" alt="Weather App Icon" width="120" />
</p>

A modern and elegant weather dashboard built with HTML, CSS, and JavaScript. It fetches real-time weather data from the OpenWeatherMap API and presents it in a clean glassmorphism-inspired UI.

## ✨ Features

- Search weather by city name
- Displays current temperature in °C
- Shows humidity and wind speed
- Updates weather icon based on conditions
- Handles invalid city names gracefully
- Responsive and visually polished layout

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
- Boxicons
- Google Fonts

## 📸 UI Preview

The app is designed with a soft translucent card layout, blurred background, and sleek weather visuals for a premium look.

## 🚀 How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Enter a city name to view live weather details.

## ⚠️ Note

The app uses an OpenWeatherMap API key in `script.js` for demonstration. For production use, consider replacing it with your own API key.
